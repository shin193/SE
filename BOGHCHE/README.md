# بقچه، نسخهٔ هشتم

فروشگاه فارسی محصولات دوخته‌شده با رابط HTML، CSS و JavaScript و سرور Node.js. کاتالوگ، حساب‌ها و دیدگاه‌ها در PostgreSQL نگهداری می‌شوند.

## اجرای محلی

به Node.js 22 یا بالاتر، pnpm و PostgreSQL 15 یا بالاتر نیاز است. یک پایگاه داده به نام `boghche` و یک کاربر مالک برای آن بسازید. نمونهٔ دستورها در `psql` با حساب مدیر PostgreSQL آمده‌اند.

```sql
CREATE ROLE boghche LOGIN;
\password boghche
CREATE DATABASE boghche OWNER boghche;
```

در پوشهٔ `BOGHCHE` فایل `.env` را بسازید و رمز پایگاه داده را در نشانی اتصال با قالب URL بنویسید.

```dotenv
DATABASE_URL=postgresql://boghche:ENCODED_PASSWORD@127.0.0.1:5432/boghche
PORT=4173
```

```sh
pnpm install --frozen-lockfile
pnpm migrate
pnpm start
```

فروشگاه را از [نشانی محلی](http://127.0.0.1:4173) باز کنید. دستور مهاجرت فایل‌های تازهٔ `db/migrations` را به‌ترتیب اجرا و ثبت می‌کند. اجرای دوباره، داده‌های اولیه را بازنویسی نمی‌کند. برای سرور پشت پراکسی HTTPS، `PUBLIC_ORIGIN` را برابر مبدأ عمومی سایت تنظیم کنید. در حالت `NODE_ENV=production`، مبدأ HTTPS الزامی است.

## داده‌ها و رابط

مهاجرت اولیه هفت دسته و هشت محصول قبلی را با شناسه‌های موجود وارد می‌کند. قیمت، عکس و موجودی اولیه نمونه‌اند. موجودی هر رنگ در `product_variants.stock` است و `image_id` می‌تواند به تصویری از همان محصول در `product_images` اشاره کند. سبد و علاقه‌مندی‌ها در مرورگر باقی می‌مانند. سبد بر اساس موجودی خوانده‌شده سقف تعداد را اعمال می‌کند. ثبت سفارش و پرداخت در این نسخه فعال نیست.

منوی تصویری دسته‌ها، لینک‌های مستقیم دسته و محصول، جست‌وجو، گالری و رنگ‌ها از داده‌های API استفاده می‌کنند. فرم ثبت‌نام حساب ایجاد می‌کند و دیدگاه با نام حساب واردشده به محصول وصل می‌شود. ثبت دوباره برای همان محصول، دیدگاه همان حساب را به‌روزرسانی می‌کند.

تصویر `dist/assets/collection.png` با ImageGen ساخته شده و کارت‌ها از برش‌های آن استفاده می‌کنند. متن درخواست در `IMAGE-PROMPT.txt` و مجوز قلم Vazirmatn در `dist/assets/OFL.txt` است.

آزمون‌ها با `pnpm test` اجرا می‌شوند. قرارداد نشست در [مستند احراز هویت](./AUTHENTICATION.md) و نتایج مرورگر و PostgreSQL در [گزارش بررسی](./VALIDATION.md) آمده‌اند.
