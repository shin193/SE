# حساب، نشست و دیدگاه بقچه

فرم‌های `dist/auth.html?mode=login` و `?mode=signup` به API همان سرور وصل‌اند. ثبت‌نام و ورود پس از تأیید نشست موفق اعلام می‌شوند. تب فروشگاه پس از دریافت پیام تغییر نشست، دوباره از سرور وضعیت حساب را می‌خواند.

رمز عبور با scrypt و نمک تصادفی هش می‌شود. سرور فقط هش شناسهٔ نشست را در PostgreSQL نگه می‌دارد. کوکی نشست HttpOnly و SameSite است و روی مبدأ HTTPS از Secure استفاده می‌کند. نشست عادی ۱۲ ساعت و گزینهٔ «مرا به خاطر بسپار» ۳۰ روز اعتبار دارد. خروج، نشست مربوط را حذف می‌کند. درخواست‌های نوشتن مبدأ مجاز و توکن CSRF را بررسی می‌کنند.

| مسیر | کاربرد |
| --- | --- |
| `GET /api/auth/csrf` | دریافت توکن برای درخواست نوشتن |
| `POST /api/auth/signup` | ساخت حساب با `name`، `email` و `password` |
| `POST /api/auth/login` | ورود با `email`، `password` و `remember` |
| `GET /api/auth/session` | دریافت نام و ایمیل حساب نشست جاری |
| `POST /api/auth/logout` | پایان نشست |
| `GET /api/categories` | نام، تعداد محصولات و تصویر دسته |
| `GET /api/products` | فهرست محصولات، با پارامتر اختیاری `category` |
| `GET /api/products/:id` | مشخصات، تصاویر و موجودی رنگ‌ها |
| `GET /api/products/:id/reviews` | فهرست عمومی دیدگاه‌های محصول |
| `POST /api/products/:id/reviews` | ثبت یا به‌روزرسانی دیدگاه حساب با `text` و `rating` |
| `DELETE /api/products/:id/reviews/:reviewId` | حذف دیدگاه توسط حساب مالک |

درخواست نوشتن ابتدا کوکی و توکن را از مسیر CSRF می‌گیرد و توکن را در هدر `X-CSRF-Token` می‌فرستد. سرور ورودی‌ها را اعتبارسنجی می‌کند. ایمیل حساب به‌صورت یکتا ذخیره می‌شود و نام نویسنده از حساب نشست خوانده می‌شود. فرم بازیابی رمز وضعیت تنظیم‌نبودن سرویس ایمیل را نشان می‌دهد.

قرقرهٔ صفحهٔ احراز هویت با دهان خنثی می‌ایستد. ثبت‌نام یک سلام کوتاه دست و تکان سر دارد و ورود با تکان سر همراه است. هنگام نزدیک‌شدن موس، نگاه و حالت غافلگیر پیش از دویدن دیده می‌شوند. کلیک، لمس و صفحه‌کلید واکنش کوتاه دارند. نمایش کاراکتر تنظیم کاهش حرکت را رعایت می‌کند. پالت قرقره مستقل از تم است و تصویر چرخ برای هر تم رنگ مکمل دارد.
