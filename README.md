# SE

## BOGHCHE — بقچه

فروشگاه فارسی و راست‌به‌چپ محصولات پارچه‌ای.

کد پروژه در پوشهٔ [BOGHCHE](./BOGHCHE) قرار دارد. برای اجرای محلی:

```sh
cd BOGHCHE
node serve.mjs
```

سپس `http://127.0.0.1:4173` را باز کنید. وابستگی خارجی برای اجرا لازم نیست.

همچنین می‌توانید `BOGHCHE/dist/index.html` را مستقیماً در مرورگر باز کنید. محصولات و قیمت‌ها نمونه‌اند و پرداخت واقعی فعال نیست.
